        Step-by-step help
        1. Process the application and complete its time trial in the usual screens.
        2. Compare the driver against All time trials. Results sort by overall average; green cells show each driver's fastest lap per track. Lap 1 is excluded from averages.
        3. Choose Place driver, then division and tier. Choose reserves or an available team seat in the same window. Part-time drivers go into reserves.
        4. Current drivers is the live roster, grouped by division. Choose Review / move for one driver, preview the next scheduled round after entered results, then Save movement. This records the move and publishes its public history.
        5. Driver details inside Review / move edits nationality, platform and controller. Team principals has the current full-team appointments.
        6. Previous results and team points stay put. Movement history shows recorded changes; private notes stay in the Master. Use Update website to refresh the full roster display.

            Help
            1. Publish final outcomes first. Select tickets below after checking each driver and session. The change columns show additions or reversals; licence totals include existing manual entries. The preview is per ticket; applying several tickets adds their changes together.
            2. Apply selected penalties. Repeat applications do not duplicate a transfer. Appeals saved with Update licence already include that transfer. Only outstanding changes appear here.

            If a penalty was already entered manually, do not transfer it again. Remove that same manual amount first, or continue handling that ticket manually. The transfer ledger lives in the permanent ticket workbook.
