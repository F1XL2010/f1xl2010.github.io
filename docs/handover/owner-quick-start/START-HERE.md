# Giving the project to another AI

You do not need to read the technical pack.

1. Give the new AI [HANDOVER-FOR-ANOTHER-AI.md](../HANDOVER-FOR-ANOTHER-AI.md).
2. Paste [this prompt](COPY-PASTE-AI-PROMPT.md).
3. If possible, give it the whole handover folder and access to the website repository too. The folder includes the detailed old notes and a dated Portal code reference.
4. Tell it what you want to do next. It should first check what access it has and explain the next step simply.

**Important:** use the updated docs/handover folder, either from this computer or from GitHub after the handover commit has been pushed. An older clone/download may still contain the original pack.

The public switch is complete. The website is https://f1xl.co.uk/ and staff use https://f1xl.co.uk/admincentre/. Old pages are at https://f1xl.co.uk/legacy/.

A different AI account does not automatically inherit your Google, GitHub or Discord access. Connect those services separately when needed; never paste passwords or tokens into the conversation.

The pack contains decisions and source references, not all the private spreadsheet data. Keep the actual Google files and recovery backups. You do not need to upload every backup to explain a small task.
